object properties / material

material

How light meets the surface. A material is a function; its colour is optional and comes first. Without one, it takes the object's color, like currentColor.

value
matte() | metal() | jelly() | glass() | <keyword>
initial
matte()
applies to
all shapes
animatable
no — animate color instead
.a { material: metal(#d4af37, 0.2); }
.b { material: jelly(0.6); }
.c { material: ice; }
costA glass pixel marches 3 more rays, 6 with blurred. Keep glass off the floor.
